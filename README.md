## Headline finding

At the moment of any Cramer recommendation, three directly observable
signal-time features plus prior disclosed ownership/hold state jointly
structure forward performance in the 2018–2024 sample:

1. **Prior disclosed engagement tier** — portfolio (confirmed Charitable Trust
   holding) > hold-recommendation (advisory hold without ownership) > casual buy
2. **Market capitalization** — the casual-buy underperformance is almost
   purely a small-cap (<\$2B) phenomenon
3. **Prior 90-day SPY-relative return** — Cramer's dip-buys on owned names
   (after ≥15% drawdowns) carry a sharply different signal from dip-buys on
   casual names
4. **VIX regime** — VIX < 30 acts as a precondition; the small-cap casual-buy
   pair trade flips sign in crises

The strongest in-sample cell is the small-cap casual-buy pair trade
conditioned on VIX < 30: **N = 350, +28.7% per position, p < 0.0001**.
All claims in this repo and the paper are *descriptive of the 2018–2024
sample* — not forward predictions.

## Quickstart

```bash
git clone https://github.com/andreskull/cramer-mad-money-research.git
cd cramer-mad-money-research
pip install -r requirements.txt
```

The published CSVs are the starting point — you don't need to re-run the LLM
classification, the frozen price matrix build, or the upstream signal-extraction
pipeline. The analysis is reproducible from the bundled post-processed artifacts.
To verify the classification quality:

```bash
python scripts/reclassify_holds.py validate
```

To reproduce the four headline figures from the published CSVs:

```bash
python scripts/fig_methodology_timeline.py        # paper §3
python scripts/study_a_market_cap.py              # paper §6.2 figures
python scripts/study_b_momentum.py                # refreshes momentum_signals.csv if needed
python scripts/make_fig_funnel.py                 # paper §6 opener
python scripts/make_fig_controls_survival.py      # paper §6.3
```

To reproduce the cluster-robust headline tables — Tables 4, 6, 7, 8, 8a — and
the BH-corrected grid (`data/bh_grid.csv`) consumed by Figure 11, run:

```bash
python scripts/replicate_headline_tables.py      # cluster-robust + QQQ + BH
python scripts/sensitivity_analysis.py           # produces sensitivity_results.csv
python scripts/visualize_sequence.py             # sequence, VIX, horizon, and BH figures
python scripts/figs_dipbuy_promotion.py          # Figures 7, 8 (promotion + dip-buy gradient)
```

Every numeric claim in §6.1–§6.2 (engagement-tier alphas, market-cap
decomposition, VIX-regime split, SPY/QQQ pair-trade benchmarks, the 5×4
specification grid, the cluster-robust t-statistics and two-way ticker ×
signal-month p-values referenced in the §6.2 verification block) is
regenerated by `replicate_headline_tables.py` and written to
`data/headline_tables.csv` for direct comparison against the paper.

`market_caps.csv`, `gics_sector_map.json`, and `daily_price_matrix.parquet` are
frozen analysis inputs. Scripts that refresh market caps or sector mappings use
live Yahoo Finance data and may drift from the paper snapshot if rerun after the
data-freeze date.

The PDF is built from the Markdown source with `scripts/build_pdf.py`. This is
optional for numeric replication and requires system tools (`pandoc` and
`xelatex`) in addition to the Python packages in `requirements.txt`.

To re-run the LLM hold-state classification step from scratch (optional —
requires an [xAI API key](https://console.x.ai/)):

```bash
cp env.example .env       # edit .env, set XAI_API_KEY
python scripts/reclassify_holds.py classify       # ~4,900 LLM calls
python scripts/reclassify_holds.py merge          # writes hold_subtype back into snapshot
python scripts/reclassify_holds.py validate
```

## Methodology recap (full detail in paper §3 and §5)

| Aspect | Rule |
|---|---|
| **Entry** | T+1 Open — the first tradeable price after the episode airs. |
| **Exit** | Fixed-horizon close (1W / 1M / 3M / 6M / 1Y). No discretionary exits. |
| **Benchmark** | SPY. Returns reported as `stock_return − spy_return` ("SPY-relative alpha"). |
| **Universe** | Long-side only — `BUY` / `POSITIVE` directional calls; shorts excluded. |
| **Weighting** | Equal-weighted — every signal counts the same. |
| **Independence** | Sequence model groups repeated mentions of the same stock (§5) and prunes overlapping observations so each tested data point is genuinely independent. |
| **Hold reclassification** | LLM-based two-stage split of 4,900 deduplicated `hold_long` classification inputs into `cramer_owns` (confirmed Charitable Trust holding) vs `hold_recommendation` (advisory hold without ownership), reducing portfolio tickers from 770 to 225 (§3). |

## Data provenance

The signal-extraction pipeline that produced this dataset is operated by
[finfluencers.trade](https://finfluencers.trade), a platform that transcribes
publicly broadcast financial-media content (CNBC *Mad Money*, podcasts,
YouTube) and identifies stock-specific directional calls from the transcripts.

The CSVs published in this repository are the **post-processed,
paper-aligned snapshots** of the platform's *Mad Money* coverage as of the
paper's data-freeze date. The pipeline itself is not included here — only the
resulting datasets and the analysis scripts that operate on them.

The underlying CNBC *Mad Money* broadcast content is the property of CNBC /
NBCUniversal and is not redistributed in this repository. Only derivative
analytical metadata (tickers, dates, computed returns, classifications) and
short verbatim transcript quotes used as evidence for hold-state
classification are included, under fair-use principles.
